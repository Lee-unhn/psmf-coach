🥗 PSMF-Coach 架構圖

自動化 PSMF 減脂教練：每日回填 → 動態菜單 email；每週日抓研究 + 趨勢分析 + 週報。純 Python / SQLite / 免費 API。

系統總覽

flowchart TD
  subgraph IN[回填（三選一）]
    F1[Google 表單\n隨地]; F2[本機表單 form.py\n即時]; F3[Google Sheet\n手動]
  end
  DB[(SQLite\npsmf.db)]
  subgraph DAILY[每日 21:05]
    R[規則引擎\n決定隔日日型]; M[菜單生成\nGemini/template]
  end
  subgraph WEEK[每週日 09:00]
    P[抓論文\nPubMed/EuropePMC]; A[趨勢分析\n重算 TDEE]
  end
  MAIL[📧 Email\n菜單卡 / 週報]
  F1 & F2 & F3 --> DB --> R --> M --> MAIL
  DB --> A; P --> DB; A --> MAIL
  M -. 記帳/menu .-> DB; A -. 調整 .-> DB

每日動態菜單規則引擎

flowchart TD
  S[讀今日回填 + 近 7 日趨勢] --> R1{排定 回補/飲食假期?}
  R1 -- 是 --> RF[隔日 = 回補/假期\n升碳水至近維持]
  R1 -- 否 --> R2{近 3 日 能量低/飢餓高?}
  R2 -- 是 --> B[B 固體日 + 熱量上緣]
  R2 -- 否 --> R3{體重停滯且依從佳?}
  R3 -- 是 --> H[維持缺口\n標記給週日深析]
  R3 -- 否 --> RT[A/B 輪替]
  RF & B & H & RT --> G[食材庫組菜單 + 算 macros/價格\n+ Gemini 教練提示]
  G --> E[寄菜單卡 + 寫 menu_plan/cost_log]

每週研究 + 趨勢分析

flowchart TD
  T[週日 09:00 觸發] --> P[抓最新論文\nPubMed / Europe PMC / Semantic Scholar]
  P --> DBP[(research_papers)]
  T --> TR[讀近 N 週 body_metrics]
  DBP & TR --> AN[分析: 減速率 / ETA / 停滯 / 減速過快]
  AN --> TDEE[依現體重重算 BMR/TDEE]
  TDEE --> ADJ[(plan_adjustments)]
  AN --> REP[產 HTML 週報\n進度 + 調整 + 最新論文 + 累計花費]
  REP --> MAIL[📧 寄出]
